# 本地／云端部署层

## 发布脱敏更新

- 账号、机器人互相识别和管理员权限均改为私有配置驱动，移除账号硬编码与隐藏管理员兜底。
- 清空本地音色 ID、云 TTS voice ID 和旧训练名称默认值；不改变本机已有私有配置和模型文件。
- 翻唱模型登记/选择改为通用模型库，首次使用全部关闭，不绑定作者使用的音色或模型来源。
- 新增私有人格创建、自己的音频预处理/训练/音色分配入口与首次配置指南。
- 导出增加已知私人值比对、硬编码检查；发布包不携带扫描的秘密清单。

- 不搬移、不删除原实例数据；统一入口、运行数据目录、Docker 配置与多 AI 路由。
- bot1～6 独立提供方和模型选择；密钥可来自环境或私有配置；网页面板读取时脱敏。
- 群记忆、人格库、唤醒名单、语音和翻唱 metadata 使用共享数据卷，账号会话分别保存。
- 默认关闭账号与 GPU 服务；端口冲突不接管旧进程；不添加 Windows 自动启动任务。
- bot1/2 使用固定 SDK 的幂等适配补丁，连接共享语音/翻唱/白名单及 bot2 玩法入口。
- 修复部署实例默认 bot ID 误读、无思考模型的 reasoning 参数冲突。
- 修复新建会话在首次轮询前已完成时丢回复：仅本客户端创建的新会话从零读取，已有历史不重放。
- GitHub 导出采用源码白名单、明显秘密扫描、SHA256 清单；不导出账号历史、权重和音源。
- 自动测试覆盖真实 DSH 自定义提供方、模拟 QQ 收发、配置保存、鉴权及官方适配。
